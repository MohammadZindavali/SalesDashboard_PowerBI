📊 Sales Dashboard – Power BI

An interactive Sales Dashboard built in Power BI to track category performance, monthly profit trends, order distribution, and regional sales — with Row-Level Security (RLS) implemented for region-based access control.

🔍 Overview

Built an end-to-end Sales Dashboard in Power BI — performed data preparation and cleaning in Power Query, designed a star schema data model, developed interactive visuals (bar, ribbon, scatter, and donut charts) for sales, profit, and regional analysis, and implemented Row-Level Security (RLS) using an access-mapping table to restrict data visibility by region.
   
🛠️ Tools Used
1. Power BI Desktop
2. DAX (measures, RLS filters)
3. Power Query (data transformation)
